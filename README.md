# 🎓 Online Courses Website

A simple and modern online courses website built with HTML and CSS.

## 📌 About the Project

This project is an online learning platform where users can explore popular courses, view course prices, and choose a course to purchase.

## ✨ Features

- Navigation header
- Hero section
- Popular Courses section
- Course images
- Course prices
- Buy Now buttons
- Hover effects
- Responsive design
- Contact information in the footer

## 🛠️ Technologies

- HTML5
- CSS3

## 🎯 Purpose

The main purpose of this project is to practice frontend development and learn how to build a website using HTML and CSS.
